# Glossaire — MANSA : L'Héritier du Fleuve

> Référence lexicale du jeu. Maintenu par l'agent `historien-mande`.
> Cadre : Empire du Mali, 1324 (année du départ de Mansa Moussa pour La Mecque).

## Comment lire ce glossaire

- **Graphie retenue** : forme à utiliser dans le jeu (UI, sous-titres, Data Tables). Les variantes sont listées pour la recherche et la cohérence.
- **Langue** : maninka (malinké) et bambara sont deux variétés proches du **mandingue** ; on note « mand. » quand la forme est commune.
- **Prononciation** : approximative, pour le doublage FR. `ny` = « gn » de *agneau* ; `u` = « ou » ; `j` = « dj » ; `ɛ` = « è » ; `ɔ` = « o » ouvert. Le mandingue est une langue à tons : à valider avec un locuteur avant enregistrement.
- **Fiabilité** :
  - **solide** : attesté par des sources médiévales, l'archéologie ou un consensus clair ;
  - **débattu** : réel, mais date, forme ou sens discutés ;
  - **hypothèse** : plausible, sans preuve pour 1324 — à présenter comme choix de jeu.
- **Statut dans le jeu** : quand on utilise un terme débattu ou une hypothèse, le griot narrateur peut l'assumer (« les anciens disent que… »).

## Notes d'usage

- Écrire les noms de peuples sans article péjoratif et jamais « tribu » : préférer *peuple*, *communauté*, *clan* (*jamu*), *corporation*.
- Les termes marqués **hypothèse** peuvent figurer dans le jeu s'ils sont présentés comme choix assumé (voix du griot, codex du jeu).
